# IronMan Gesture Reference Guide

This directory contains high-confidence textbook examples of all 9 gestures recognized by the STARK OS / IronMan system.

| File | Gesture | Triggered Action | How to Perform |
|---|---|---|---|
| `01_grabbing_AltTab_Trigger.jpg` | **GRABBING (Closed Fist)** | `Engage Modal Alt-Tab (Holds Alt)` | Clench hand into a closed fist in camera view |
| `02_point_AltTab_Navigate.jpg` | **POINT (Directional)** | `Navigate Windows (Point Right = Next, Left = Prev)` | Extend index finger horizontally to the left or right |
| `03_stop_AltTab_Release.jpg` | **STOP (Open Palm)** | `Lock-In Selected Window (Releases Alt)` | Flat open palm facing camera with all fingers spread |
| `04_xsign_CloseTab.jpg` | **X-SIGN (Crossed Arms)** | `Close Active Tab / Window (Ctrl + W)` | Cross both forearms over chest into an 'X' shape |
| `05_thumb_index2_ToggleDesktop.jpg` | **THUMB_INDEX2 (Inward Guns)** | `Show / Hide Desktop (Win + D)` | Two hands with thumbs up and index fingers pointing inward |
| `06_hand_heart_LaunchSteam.jpg` | **HAND_HEART (Love Pose)** | `Launch & Focus Steam Client` | Both hands joined together forming a heart shape |
| `07_take_picture_Screenshot.jpg` | **TAKE_PICTURE (Frame Photo)** | `Fullscreen Screenshot (Win + PrtScn)` | Two hands forming opposing 'L' corners framing a camera view |
| `08_mute_ToggleVolume.jpg` | **MUTE (Shush Pose)** | `System Volume Mute Toggle` | Single index finger held vertically in front of lips |
| `09_no_gesture_Resting.jpg` | **NO_GESTURE (Neutral / Idle)** | `Idle / Hands Down / Typing (No Action)` | Hands at rest, on keyboard, or casual posture |
